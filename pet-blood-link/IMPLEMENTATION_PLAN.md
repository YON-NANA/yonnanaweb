# Pet Blood Connect (仮) - 実装計画書

## 1. プロジェクト概要

**目的**: 全国の動物病院・飼い主と、愛犬・愛猫の供血ボランティア（ドナー）を繋ぐマッチングプラットフォームの構築。
**理念**:

- 金銭の授受なし（完全ボランティアベース。謝礼禁止）
- プライバシー保護（連絡先はマッチング成立まで非公開。チャットは匿名で開始）
- 安全・安心（運営は「場の提供」に徹する。医療行為・適合試験は病院の責任）
- **病院認証制**: 一般公開の検索はせず、認証された動物病院のみがドナーを検索・依頼できる。
- 運営費は広告収入（企業・店舗広告）で賄う

## 2. ターゲットユーザー

- **ドナー協力者**: 愛犬・愛猫を登録し、いざという時に協力してくれる飼い主。
- **依頼者（動物病院）**: 手術や緊急時に血液を必要としている獣医師。※一般飼い主からの直接依頼はトラブル防止のため不可とするか、病院経由を原則とする。
- **協力パートナー（動物保護団体）**: 全国の保護団体。里親ネットワークを通じてドナー登録を呼びかける「広報・普及のハブ」。

## 3. 技術スタック (提案)

- **フレームワーク**: [Next.js](https://nextjs.org/) (Reactベースの最新フレームワーク。SEOに強く、高速)
- **スタイリング**: [Tailwind CSS](https://tailwindcss.com/) (美しくモダンなデザインを効率的に構築)
- **PWA (Progressive Web App)**:
  - スマホアプリとしてインストール可能（iOS/Android）。
  - ネイティブアプリ開発コストを抑えつつ、アプリのような体験を提供。
- **バックエンド/DB (本番環境想定)**:
  - [Supabase](https://supabase.com/) (Google Firebaseの代替。認証、データベース、リアルタイムチャット機能を提供)
  - ※開発段階ではモックデータまたはローカルDBを使用。

## 4. 機能要件

### A. ユーザー機能

1. **トップページ (LP)**
    - コンセプト「命を繋ぐ」。現在のドナー登録数をリアルタイム表示（目標）。
    - 協力病院向けの案内・ログイン入り口。
    - 広告スペース（「ドナー協力店」としての掲載など）。
    - **協力保護団体募集**: パートナー団体のロゴ・活動紹介エリア。
2. **ドナー登録 (飼い主)**
    - **基本情報**:
        - **種類**: 犬 / 猫
        - **体重**: 重要（供血量の目安。犬>20kg, 猫>4kgが望ましいなどの基準あり）
        - **年齢**: 1歳〜7歳程度（推奨）
        - **血液型**: わかれば入力（犬: DEA 1.1 +/-, 猫: A/B/AB）。不明でも可。
        - **居住地域**: 都道府県・市区町村まで。
    - **証明書アップロード (必須)**:
        - 混合ワクチン接種証明書
        - （任意）狂犬病予防接種証明書（犬の場合）
        - ※これにより「冷やかし」や「管理不届き」な層をフィルタリング。
    - **詳細問診票**:
        - 「過去1年以内に混合ワクチンを接種していますか？」
        - 「現在、投薬中の薬はありますか？」
        - 「過去に輸血を受けたことがありますか？」
    - **3者間契約への同意**:
        - ドナー（提供者）：健康状態の真実ご申告、リスク承諾。
        - レシピエント（受血者）：ドナーへの感謝、不可抗力時の免責、費用全額負担。
        - 病院：医療行為の提供のみに責任を持ち、マッチングの成否には関与しない。

3. **病院専用機能 (要ログイン)**
    - **ドナー検索**: 地域、体重、血液型、**評価（過去の協力履歴）**で絞り込み。
    - **依頼送信**: 候補のドナー飼い主に「協力依頼」を送る。
    - **ドナー評価**: 輸血完了後、協力的な対応だったかを評価（星評価など）し、信頼性を担保。

4. **チャット・連絡機能 & 契約締結**
    - **フロー**: 病院からの依頼 -> 飼い主に通知 -> 飼い主が「承諾」 -> チャットルーム開通。
    - **合意形成**: チャットで日時等が決まったら、システム上で**「マッチング成立（合意）」**ボタンを押す。
    - **デジタル合意証**: 「無償確認」「免責事項」「守秘義務」を明記した合意書が自動発行され、双方が確認。
    - **匿名性**: 病院へ行くまでは名前・住所・連絡先を明かさず相談可能。
    - LINE風のUI。

### B. 運営・収益化機能

1. **病院認証システム**
    - 審査制または招待制。無資格者による悪用を防ぐ。
2. **保護団体パートナー制度**
    - **役割**: 里親（卒業生）への周知、ドナー登録の呼びかけ。
    - **メリット**:
        - サイト上に「公式パートナー」として活動紹介・リンク掲載（支援の輪を広げる）。
        - 運営収益の一部を協力団体へ寄付するエコシステム（将来構想）。
3. **広告管理**
    - 地域企業、ペット関連企業のバナー。
    - 「ドナー協力店」バッジの表示。
4. **免責事項・利用規約**
    - 初回登録時に必ず同意を得るフロー。
